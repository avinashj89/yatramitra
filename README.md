# YatraMitra

A trip-planning Android app: plan a route (with Google Maps handoff), build a
day-by-day itinerary table, and split trip expenses live with your travel
group, Splitwise-style.

**New to this project? Start with [SETUP_GUIDE.md](SETUP_GUIDE.md)** — it
walks through turning this code into an installed app on your phone, with no
coding knowledge required.
