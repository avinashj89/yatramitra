# YatraMitra

A collaborative trip-planning Android app for a travel group: one person
organizes a shared trip (route, day-by-day itinerary, expenses), everyone else
joins with a short code, and the route, itinerary, and expenses all stay live-synced
across every phone. Plan a route with Google Maps handoff, build a day-by-day
itinerary, split expenses (equally, by percentage, or exact) with UPI settle-up,
and let joiners suggest changes for the organizer to accept.

**New to this project? Start with [SETUP_GUIDE.md](SETUP_GUIDE.md)** — it
walks through turning this code into an installed app on your phone, with no
coding knowledge required.
